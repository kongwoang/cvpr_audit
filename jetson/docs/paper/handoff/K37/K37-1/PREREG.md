## Rule (c), fixed now
1. For each row (cheap, u960 + C1 + v3a, native + C1 + v3a, hybrid tsp8, DESP) and each dev dataset (nuScenes new
   val; AV2 CFG-DEV with the ego mask), compute the dev missed rate at each grid threshold. This is the K31 required
   episode missed rate, L = 1, all episodes.
2. **Constraint:** dev missed rate ≤ **cheap's dev missed rate at thr 1.0** on the same dataset.
3. **Choice:** the **largest** thr_decel in the grid that satisfies the constraint (one threshold per row and
   dataset).
4. **Transfer:** nuScenes test uses the nuScenes dev choice. AV2 test uses the AV2 dev choice. **Argoverse-HD test and
   the holdout use the AV2 dev choice**, as for the frozen configuration.
5. **Infeasible:** if no grid threshold meets the constraint for a row on dev, report "infeasible" for that row and
   dataset, plus its lowest-missed-rate dev point (largest threshold on ties).
   - Infeasible rows are evaluated at that lowest-miss point, labelled as not meeting the constraint.
   - If DESP is infeasible, the paired comparisons are made against DESP's lowest-miss point, labelled accordingly.
6. **Single evaluation:** each chosen point is evaluated **once** on the three test splits (post-hoc) and **once** on
   the holdout.
   - The test splits are recomputed for all five thresholds (K37-1(b)); the chosen point is read from them.
   - On the holdout only the chosen thresholds are needed. The run computes the full grid, but only the chosen point
     of each row is analysed and reported for the holdout.
7. **Reported per row, at its chosen point:** G, false episodes per 1,000, missed rate (all; below / at-or-above hard),
   mean network px.
   - Paired unit bootstrap intervals (2,000 draws, seed 0) of row − DESP at **DESP's constrained point**.
   - Every row is reported, whatever the outcome. No other threshold, row or split is chosen on test or holdout numbers.

## K37-1(b) (descriptive, no selection)

# K38-1 — in-loop deadline execution on the Jetson (registered 2026-10-26, before the window)

- **Runtime.** K29 fast path (trt32) + K35 timing-note runtime (FAST_RECOVERY helper, RUNTIME_20261023 crop staging).
  - Harness: scripts/88_k38.py, generated by build.py from the K35-4 K29 harness. deadline.py holds verbatim copies of
    vtf.speculative.run and bounded_keep, with a stop hook and a time-mark hook only.
- **Rows** (same process, rotated order, each with its own history):
  - v6-S and B2K-A at D = ∞;
  - v6-S and B2K-A under D ∈ {50, 66.7} ms;
  - u960 + C1 + v3a.
- **Deadline rule (DESP and B2K-A).** Before each round, stop if elapsed + median(duration of the next round) +
  median(finish = refiner + action) > D.
  - DESP then returns the action of the merged scene of the last completed round. The draft round is always available.
  - B2K-A stops exactly as if its cap were reached (pending truncated detections retained).
  - The medians per dataset / pipeline / round index are measured on the dev prefixes, with no stopping:
    - nuScenes val and the verified AV2 CFG-DEV manifest;
    - first 712 frames, 200 warm-up;
    - 1 repetition, in the same window before any test run;
    - written to medians.json, whose sha256 is recorded in logs/state.json.
- **Applied action under D.** If a row's actual latency still exceeds D (the round itself overran, or u960 finished
  late), the frame keeps the row's last on-time action (K37-2 rule (a), hold).
  - For u960 + C1 + v3a this is applied to its own run: its computation does not depend on D, so the hold is exact.
- **Frames.**
  - nuScenes: the K29 test 20 scenes (805 timed frames after the 200-frame warm-up pass).
  - AV2 test (val), the 40 first logs in sorted order (av2_test40_logs.txt; the K29 8 timed logs are logs 3–10, the
    first 200 frames are the warm-up as in K29). Ego mask 1830.
  - Data copied to ~/datasets/k38 (a separate tree; DEEP's ~/datasets/av2 untouched): only the frames AV2Log selects,
    plus metadata.
- **Repetitions.** Three staged repetitions.
  - Plus one reference-runtime run per dataset (D = ∞ rows + u960), for the K35 timing-note parity on every timed frame.
  - Plus the 80-frame smoke parity.
- **Report.**
  - G, deadline-miss share, missed and false episodes (K31, L = 1), mean / p95 latency;
  - paired unit bootstrap (2,000, seed 0, repetitions nested in units) of row − DESP@D;
  - D = ∞ parity of v6-S / B2K-A with K34-3 jetson_frames.csv on the K29 frames.
  - Everything is post-hoc; every row is reported.
